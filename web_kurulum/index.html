Rumy'yi tarayıcıdan kur Install Rumy from your browser

ESP32-2432S028R ("Cheap Yellow Display") için masaüstü arkadaşı: saat, hava durumu, deprem, maç takibi, Spotify, WiZ ampul ve Claude Code / Codex ışığı. Python ya da esptool gerekmez; kartı USB'den bağla ve kur.

A desk companion for the ESP32-2432S028R "Cheap Yellow Display": clock, weather, earthquakes, live football, Spotify, WiZ bulb control and a Claude Code / Codex agent light. No Python or esptool needed: plug the board in over USB and install. The device's interface is in Turkish.

Bu tarayıcı USB seri bağlantıyı desteklemiyor. Bilgisayarda Chrome ya da Edge kullan. This browser has no Web Serial support. Use desktop Chrome or Edge. Kurulum yalnızca HTTPS üzerinden çalışır. Installing only works over HTTPS.

Karttaki her şey silinir (Bruce, Launcher, eski Rumy ayarları). Kurulum penceresinde "Erase device" seçeneğini işaretle. Ayarlarını koruyarak güncellemek için README'deki güncelleme adımlarını kullan.

Everything on the board is erased (Bruce, Launcher, previous Rumy settings). Tick "Erase device" in the install dialog. To update while keeping your settings, follow the update steps in the README.

Kurulumdan sonraAfter installing

  1. Telefonla Rumy-Kurulum ağına bağlan (ekrandaki QR kodu okutabilirsin).
  2. Configure WiFi'ye bas, ev ağını (2,4 GHz) seç ve şifreni yaz.
  3. Adın ve Şehir (il) alanlarını doldurup Save'e bas. Rumy bağlanıp yeniden başlar.
  4. Sayfa kendiliğinden açılmazsa tarayıcıda http://192.168.4.1 adresine git.
  1. Join the Rumy-Kurulum WiFi network with your phone (or scan the QR code on screen).
  2. Tap Configure WiFi, pick your home network (2.4 GHz only) and enter its password.
  3. Fill in your name and city (a Turkish province; a custom location can be set later), then Save. Rumy connects and restarts.
  4. If the page does not open by itself, browse to http://192.168.4.1.

BağlanamıyorsaIf it will not connect

  • Kablonun veri taşıdığından emin ol; yalnızca şarj eden kablolar kartı göstermez.
  • Windows'ta CH340 sürücüsü gerekebilir.
  • Kart yükleme moduna girmezse: BOOT'a basılı tut, RST'ye bas-bırak, BOOT'u bırak, sonra tekrar dene.
  • Make sure the cable carries data; charge-only cables never show the board.
  • Windows may need the CH340 USB driver.
  • If the board will not enter download mode: hold BOOT, press and release RST, release BOOT, then retry.
