Rumy SD card contents
=====================

(Turkish: OKUBENI.txt)

1. Format the SD card as FAT32 (32 GB and smaller cards work best).
2. Copy the "rumy" folder in this directory to the ROOT of the card:
     /rumy/img/64, /rumy/img/48, /rumy/img/28, /rumy/img/24   weather icons (Meteocons, MIT)
     /rumy/events.json                                         personal special days (edited from the web app)
3. Rumy creates the /rumy/cache and /rumy/holidays folders itself.
4. If you use Launcher, also copy dist/Rumy.bin to the root of the card.

Rumy still works without an SD card; a simple fallback icon set in flash is used for the
weather icons and a warning card is shown on the home screen.
